# Hunter Reborn

**Keeping the hunt alive.**

Hunter Reborn is a community-driven preservation project dedicated to keeping **theHunter Classic** alive following the shutdown of its official servers on 11 November 2026.

The project aims to recreate the original online experience through replacement server infrastructure, allowing players to continue enjoying the game beyond the lifespan of its official services.

**Early Access**

**Hunter Reborn is currently in Early Access.** Development is ongoing, and not all features and functionality from the original game have been restored. Players may encounter bugs, incomplete features, and unexpected issues.

## About the Project

With the official theHunter Classic servers now shut down, the original game client can no longer access its online services.

Hunter Reborn aims to address this by developing replacement backend infrastructure that recreates the services required by the original game client.

The goal is to preserve as much of the original experience as possible, allowing players to continue hunting, managing their equipment, and exploring the world of theHunter Classic.

## Why Do I Need the Hunter Reborn Launcher?

The original theHunter Classic client was designed to communicate directly with the official game services. Since those services have shut down, the game requires an alternative way to communicate with its replacement infrastructure.

The Hunter Reborn launcher provides this functionality.

The launcher runs a **local reverse proxy** that intercepts and forwards the game's web traffic to Hunter Reborn's servers. This allows the original game client to communicate with our replacement services without requiring modifications to the game executable.

The launcher also provides access to the Hunter Reborn website, which is built using modern web technologies to provide an updated interface and additional functionality.

## Installation

Before using Hunter Reborn, you'll need a compatible installation of theHunter Classic.

Please follow the instructions in **[SETUP](SETUP.md)** for a step-by-step installation guide.

The guide covers:

- Initial launcher configuration.
- Configuring your Windows hosts file.
- Checking your supported game version.
- Downloading the required game version through Steam.
- Disabling automatic updates and creating a separate game installation.

**Currently supported game version:** `2026081804`

## Early Access & Development

Hunter Reborn is actively being developed. As an Early Access project, functionality is being restored and improved over time.

Please keep in mind:

- Not all original game features are currently available.
- Bugs and unexpected behaviour are possible.
- Server functionality and game compatibility may change between releases.
- Features may be incomplete or subject to change.

Feedback and bug reports are appreciated and help improve the project.
